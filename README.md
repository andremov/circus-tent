# circus-tent

Installers for Circus and the apps it installs. This repo holds no source code, only releases.

## Downloads

Each app has two kinds of release:

- `<app>-latest` always holds the newest version. Link to this one.
- `<app>-v<version>` holds one version and never changes, for going back to an older one.

For example, the newest Circus for Windows is in the `circus-desktop-latest` release.

Every release is built and published by GitHub Actions. Nothing here is built by hand.
